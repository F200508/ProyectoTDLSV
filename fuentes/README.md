# Fuentes

Material de referencia de instituciones de lengua de señas, usado para diseñar `src/tdlsv/datasets/lsa_labels.py`. Sin código — solo documentos de consulta.

## Alfabeto-Manual-Argentino-LSA-CAS.pdf

- **Institución**: CAS — Confederación Argentina de Sordos, Departamento LSA-CAS.
- **URL**: https://cas.org.ar/wp-content/uploads/2022/09/Alfabeto-Manual-Argentino-LSA-CAS.pdf
- **Consultado**: 2026-08-20.
- **Contenido**: afiche oficial del abecedario dactilológico argentino (27 símbolos: A-Z más CH y Ñ, sin LL/RR). Base para identificar qué letras son bimanuales (J, Ñ, W, X) y cuál es dinámica/se traza en el aire (Z).
